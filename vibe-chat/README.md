# 🌊 Vibe Chat

チームの生産性と創造性を加速させる、次世代コラボレーションハブ。
WebSocket によるリアルタイムチャットに、ライブ・ファイル共有、インライン共同編集ドキュメント、拡張ステータス「フロー」を組み合わせています。

## 起動方法（GitHub Codespaces）

```bash
cd vibe-chat
npm install
npm start
```

- 起動すると `http://localhost:3000` で待ち受けます。Codespaces では「ポート」タブに 3000 番が自動で転送されるので、🌐 アイコン（ブラウザーで開く）から開いてください。ターミナルにも `https://<codespace名>-3000.app.github.dev` が表示されます。
- 表示名を入れるだけでログインできます（認証なし。同じ名前なら同じユーザー）。
- **複数人の動作を試すには**、通常ウィンドウとシークレットウィンドウなど別々のブラウザーで、別の名前でログインしてください。
- ポート番号は `PORT=4000 npm start` のように変更できます。

## 機能

### コア機能
| 機能 | 内容 |
| --- | --- |
| リアルタイムチャット | WebSocket で即時配信。Markdown 対応、`@名前` / `@here` メンション、リアクション、削除、入力中表示 |
| チャンネル（グループチャット） | `#general` `#random` `#dev` を初期作成。サイドバーの「＋」で追加 |
| ダイレクトメッセージ | サイドバーのメンバーをクリック。DM は当事者以外には配信されません |
| スレッド | メッセージにホバー →「💬」で右パネルにスレッドを表示。返信数・参加者をメッセージ下に表示 |
| オンラインステータス | オンライン / 離席（5 分操作なしで自動、手動切替も可）/ 集中モード / オフライン |
| カスタムステータス | 絵文字＋テキスト、自動クリア（30 分〜今日中） |

### イケてる機能
- **ライブ・ファイル共有**
  - チャット画面やスレッドにファイルをドラッグ＆ドロップ（📎 ボタン・クリップボード貼り付けも可、50MB まで）
  - アップロードの進捗バーが **会話の参加者全員にリアルタイム表示** され、完了と同時に共有されます
  - 簡易プレビュー：画像サムネイル、動画・音声プレーヤー、テキスト/コードの冒頭表示、Markdown のレンダリング、PDF ビューア
- **インライン共同編集ドキュメント**
  - チャットで `/doc タイトル` または 📝 ボタンで作成 → 会話にカードが投稿され、誰でも開いて編集できます
  - Operational Transformation（OT）による同時編集。他の人のカーソル位置を名前付きで表示、日本語 IME の変換中も崩れません
  - 編集 / 分割 / プレビューの切替。ファイルをドロップすると画像やリンクとして挿入
- **拡張ステータス「フロー」**
  - 🎯 集中モード（通知オフ）/ 💡 ブレスト中 / 📝 資料作成中 / 👀 レビュー中 / 🗣 会議中 / ☕ 休憩中 / ✨ カスタム
  - サイドバーの「いまのフロー」に全員の活動と残り時間を表示。ブレスト中の人には「🙌 参加する」、作業中の人には「💬 声をかける」
  - 集中モードの人に DM・メンションしようとすると「通知は届かない」ことを事前に表示
  - 集中モード中は通知を止め、終了時に「おかえりなさい！ N 件のメッセージが届いていました」とまとめて知らせます

### スラッシュコマンド
| コマンド | 動作 |
| --- | --- |
| `/doc 週次振り返り` | 共同編集ドキュメントを作成して開く |
| `/focus 25 設計書` | 25 分の集中モード（分とテーマは省略可） |
| `/brainstorm 新機能の名前` `/writing 四半期レポート` `/review PR #42` `/meeting 定例` `/break` | 各フローを開始（先頭に分数を付けると時間指定） |
| `/done` | フローを終了 |
| `/status 午後は外出` | カスタムステータスを設定 |
| `/help` | コマンド一覧 |

## 構成

```
vibe-chat/
├── server.js          # HTTP + WebSocket サーバー（状態管理・アップロード・OT の適用）
├── public/
│   ├── index.html
│   ├── style.css
│   ├── app.js         # クライアント（UI・WebSocket・共同編集エディタ）
│   └── ot.js          # テキスト OT（サーバー/ブラウザ共用）
├── test/smoke.test.js # OT のランダムテスト + 2 クライアントでの結合テスト
└── data/              # 実行時に作成（state.json とアップロードファイル。git 管理外）
```

- 依存パッケージは `ws`（WebSocket）、`marked`（Markdown）、`dompurify`（HTML サニタイズ）のみ。
- 状態はメモリに保持し、`data/state.json` に自動保存します。リセットしたいときはサーバーを止めて `data/` を削除してください。

## 注意（ハンズオン用の簡易実装です）
- 認証はありません。名前を入れれば誰でもそのユーザーとして参加できます。
- アップロードしたファイルは URL を知っていれば取得できます。HTML / SVG などスクリプトを含みうる形式はダウンロード扱いで配信します。
