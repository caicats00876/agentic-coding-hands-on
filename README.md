# Agentic Coding Hands-on Portal

このリポジトリは、AgenticCoding.pdf に基づいたハンズオンを行うためのポータルです。ハンズオンで作成するプロダクトのリポジトリも含めて1つのレポジトリで完結します

## 開発環境

GitHub Codespaces　を使用します。
ブラウザは Google Chrome の最新版を使用してください。

> [!NOTE]
> GitHub Codespacesはクラウド上のVS Code開発環境です。
> - **IDE**: ブラウザ上でVS Codeと全く同じ操作感。拡張機能（Clineなど）も追加可能
> - **Git連携**: GitHubリポジトリと強力連携。ブランチ作成・コミットがスムーズ
> - **安全な環境**: Linux仮想環境（Dev Container）で動作。ローカルPCに影響なし

### 推奨環境

ドキュメントとIDEを同時に参照しながら開発を進めることと、ノートPCの画面ではIDEの表示には狭すぎるため、16インチ（解像度2560x1600）以上の外付けモニタの使用を推奨します。安価なものでも十分です。

**外付けモニター参考例:**
- [モバイルモニター 16インチ 2560x1600](https://www.amazon.co.jp/s?k=モバイルモニター+16インチ+2560+1600)


## ハンズオンの進め方

1. `docs/` フォルダのドキュメントを順に読み進めてください。
2. 各章に対応するタスクを実行します。
3. ハンズオン中に作成される設計書やコードは、このリポジトリ内で管理されます。

## 各章のトピックと学習目標

### Part1 LLMユーザーとしての基礎知識
この章では、Large Language Model (LLM) の基本概念について学びます。

#### 主要なトピック
- LLMの概要と仕組み
- LLMを活用するための基礎知識

#### 学習目標
- LLMがどのように動作するかを理解する
- ハンズオンで使用する技術の背景知識を得る

### Part2 Coding Agentの基礎知識
この章では、エージェントの基本概念と自律型AI開発の理論について学びます。

#### 主要なトピック
- エージェントの定義と役割
- 自律型AI開発の構造
- AIエージェントに関連する技術と概念

#### 学習目標
- エージェントベースのシステムの基本を把握する
- Coding Agentの構造と理論を理解する

### Part3 Vibe Codingを試してみよう
この章では、ハンズオンで使用する開発環境のセットアップと、Vibe Codingの実践を行います。

#### 主要なトピック
- CodespacesとDevContainerによる隔離された環境構築
- Clineのインストールと初期設定
- Vibe Codingの実践とプロトタイプ作成

#### 学習目標
- Codespaces上で開発環境を構築する手順を習得する
- Clineを活用した基本的な開発ワークフローを理解する
- 実装の詳細をエージェントに委ねて素早く開発するVibe Codingの手法を体感する

### Part4 Agentic Codingに向けて
この章では、Coding Agentとの協働において発生しがちな問題と、それらに対する「正しい委ね方の作法」について学びます。

#### 主要なトピック
- Vibe Codingの課題と限界
- 要件定義の具体化と自動テストの積極採用
- 規約・スタイルの維持
- セーフティネットとしてのガードレール整備（バージョン管理、開発環境の隔離、権限管理、継続的インテグレーションの整備）

#### 学習目標
- エージェントに開発を委ねる際に見られる曖昧な要件やスタイルの不統一などの課題を理解する
- Agentic Codingを成功に導く基盤となる「4つの作法」を身につける

### Part5 Agentic Coding - 開発基盤構築
この章では、モノレポ構成の構築やセキュリティ強化など、実務に耐える開発基盤の作り方について学びます。

#### 主要なトピック
- プロジェクト固有のルールとWorkflowsの定義
- モノレポ構成と仕様駆動開発の準備
- セキュリティおよび継続的インテグレーション（CI）の整備

#### 学習目標
- エージェントと安全かつ効率的に開発を進められる環境を構築する
- モノレポを効果的に運用するための設定を行う
- 仕様に基づいた開発の土台となるプロセスを実践する

### Part6 Agentic Coding - コーディング
この章では、構築した開発基盤の上で、要求仕様から実際のアプリケーション実装までをエージェントと共に行います。

#### 主要なトピック
- 仕様駆動開発による設計書の自動生成と分割
- 共通部分・バックエンド（Hono）・フロントエンド（React/Vite）の実装
- テスト駆動開発（TDD）とセルフチェックによる品質維持

#### 学習目標
- 仕様に基づいた開発プロセスを実践する
- タスクを細分化し、各イテレーションでテストとLintを確認しながら進める手法を学ぶ
- 鵜呑みにせず自己レビューや人間による最終確認を組み合わせたAIとの協働ワークフローを理解する

### Part7 Agentic Coding - リリース
この章では、開発したアプリケーションをAWS環境にデプロイし、リリースするプロセスについて学びます。

#### 主要なトピック
- MCPサーバーの活用（AWS Knowledge / AWS CDK）
- AWS CDKを用いたインフラのコード化
- GitHub Actionsを用いたCI/CDパイプラインの構築と自動デプロイ
- デプロイ後のE2Eテストの実装とデバッグ

#### 学習目標
- MCPサーバーを活用し、最新のドキュメントやベストプラクティスを生成に組み込む
- エージェントと協働しながら、安全にデプロイを実行するためのCI/CDを構築する
- デプロイ後の機能不具合をE2Eテストで発見・修正し、段階的に品質を高める
