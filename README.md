# Agentic Coding Hands-on Portal

このリポジトリは、AgenticCoding.pdf に基づいたハンズオンを行うためのポータルです。ハンズオンで作成するプロダクトのリポジトリも含めて1つのレポジトリで完結します。

## ハンズオンの進め方

1. `docs/` フォルダのドキュメントを順に読み進めてください。
2. 各章に対応するタスクを実行します。
3. ハンズオン中に作成される設計書やコードは、このリポジトリ内で管理されます。
