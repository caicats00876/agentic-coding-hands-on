# 試走ログ

教材改善のため、試走中に見つかった問題を Day ごとに記録します。教材そのものの修正は行わず、修正案として残します。

記録の形式：日時 / Day とステップ / 起きたこと / 原因 / 教材の修正案

## Day1

### 2026-10-16 / Day1 ハンズオン 1（事前確認）

*   **起きたこと**：手順が「Create codespace on main」固定のため、試走（trial-run ブランチ）では読み替えが必要。
*   **原因**：本番の fork 運用のみを想定した記述。
*   **教材の修正案**：講師ガイドの「リハーサル」に、試走時は対象ブランチ（例：trial-run）で Codespace を作成する旨の注記を追加する。

### 2026-10-16 / Day1 オリエンテーション（スライド）

*   **起きたこと**：オリエンテーションでスライド 1〜6 を使用。ミニ講義「LLM と Coding Agent の要点」「Vibe Coding とは」に対応するスライドがなく、口頭のみで説明した。
*   **原因**：スライドは研修全体の概要説明用で、各日のミニ講義用ページを含んでいない。
*   **教材の修正案**：ミニ講義用のスライド（LLM・コンテキスト・エージェントループ、Vibe Coding の定義とルール）を追加する。または講師ガイドに「各時間帯でどのスライドを使うか」の対応表を載せる。

### 2026-10-16 / Day1 オリエンテーション（スライド構成）

*   **起きたこと**：同じデッキに受講者向けのページと講師向けのページ（「評価の観点」「講師の事前準備」）が混在している。受講者に全ページを見せる運用だと、評価観点や運営の内情まで見える。
*   **原因**：1 つのデッキで研修説明と講師向け説明を兼ねている。
*   **教材の修正案**：講師向けページを別デッキに分けるか、講師ガイドに「受講者に見せるのはスライド X〜Y」と明記する。

### 2026-10-16 / Day1 ハンズオン 1（Codespaces の起動）

*   **起きたこと**：trial-run の Codespace が「recovery mode due to a configuration error」で起動し、devcontainer の設定が適用されなかった（Claude Code 拡張などが入らない）。
*   **原因**：`.devcontainer/devcontainer.json` のイメージタグ `mcr.microsoft.com/devcontainers/typescript-node:1-24-bookworm` が MCR に存在しない（`1-` 系は Node 20/22 のみ）。Node 24 のタグは `24-bookworm`、`4-24-bookworm`、`3-24-bookworm` など。
*   **教材の修正案**：イメージを `mcr.microsoft.com/devcontainers/typescript-node:24-bookworm`（またはメジャー固定の `4-24-bookworm`）に変更する。講師ガイドの「リハーサル」に、devcontainer のイメージタグが存在することの確認を追加する。致命的（全員の環境構築が止まる）なので、本番前に必ず修正する。
