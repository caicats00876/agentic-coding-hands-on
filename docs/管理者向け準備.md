# 管理者向け準備

この研修は、受講者が AI チューターと一緒に一人で進める自学自習型です。人間の講師は置きません。
このページは、受講者が研修を始める前に、管理者が用意しておくものをまとめています。

## 受講者に配布するもの

*   [ ] **社内契約の Claude アカウント**（自社のメールアドレス）。Claude デスクトップアプリ、Claude in Chrome、Claude Code（VS Code 拡張）で使います
*   [ ] **Claude デスクトップアプリ**のインストール
*   [ ] **Google Chrome**のインストール
*   [ ] 研修リポジトリの入手方法
    *   公開リポジトリの場合：URL を伝えます
    *   非公開の場合：リポジトリの ZIP を配布します（AI チューターの起動に使います）

## 受講者の PC と社内ポリシー

*   [ ] Chrome に**拡張機能（Claude in Chrome）を追加できる**
*   [ ] 自社のメールアドレスで、**作業用の Google アカウント**と **GitHub アカウント**を作成してよい
*   [ ] Claude デスクトップアプリから、研修リポジトリのフォルダを読めるようにしてよい

## GitHub と Codespaces

受講者は、自分の GitHub アカウントに研修リポジトリを fork して Codespaces を使います。

*   [ ] Codespaces の利用枠の考え方を決めている
    *   個人アカウントの無料枠では、4 コアの Codespace は月に約30時間です。研修を受け切るには余裕がありません
    *   会社で費用を負担する場合は、Organization での運用や請求先の設定を検討します
*   [ ] ポートの公開範囲を Public にしないことを、受講者に周知している（教材にも記載済み）

## リハーサル

*   [ ] 研修リポジトリから新しく Codespace を作成し、「recovery mode」にならないことを確認している（devcontainer のイメージタグが存在するかを含む）
*   [ ] Claude Code 拡張と devcontainer が、研修当日のバージョンで動くことを確認している
*   [ ] Claude デスクトップアプリで `tutor/` を開き、AI チューターが起動することを確認している
*   [ ] （任意）Vibe Order の完成版を、救済用のリファレンス実装として別ブランチに用意している

## 受講者からの問い合わせ

AI チューターが解決できない問題（アカウントの割り当て、契約、社内ポリシー、教材の誤り）は、受講者から管理者に問い合わせてもらいます。問い合わせ先を受講者に伝えておいてください。
