# 管理者・研修担当者向け準備

この研修は、受講者が AI チューターと一緒に一人で進める自学自習型です。人間の講師は置きません。
このページでは、受講者が研修を始める前に用意しておくものを、**管理者**（情報システムなど）と**研修担当者**に分けてまとめています。

## 管理者が受講者に配布するもの

*   [ ] **社内契約の Claude アカウント**（Team プラン以上、自社のメールアドレス）。Claude デスクトップアプリ、Claude in Chrome、Claude Code（VS Code 拡張）で使います
*   [ ] **Claude デスクトップアプリ**のインストール
*   [ ] **Google Chrome**のインストール

## 受講者の PC と社内ポリシー（管理者が確認）

*   [ ] Chrome に**拡張機能（Claude in Chrome）を追加できる**
*   [ ] 自社のメールアドレスで、**作業用の Google アカウント**と **GitHub アカウント**を作成してよい
*   [ ] Claude のプロジェクトを、**組織内に共有**できる（共有の設定で「（会社名）の全員」を選べる）

## 研修担当者が用意するもの

研修担当者は、Claude の**ユーザー権限**で作業できます。管理者の権限や GitHub の Organization は要りません。

*   [ ] **AI チューターのプロジェクト**を作り、組織内に共有する。手順は [プロジェクトの作り方](../tutor/プロジェクトの作り方.md) にあります
*   [ ] 受講者に、次の3点を伝える
    *   研修リポジトリの URL（fork 元）：https://github.com/caicats00876/agentic-coding-hands-on
    *   AI チューターのプロジェクト名：「AgenticCoding研修」
    *   始め方：Claude デスクトップアプリのチャット → プロジェクト → 組織 タブ → プロジェクトを開き、「研修を始めて」と入力する（[README の「受講の準備」](../README.md#受講の準備)）
*   [ ] 受講者からの問い合わせ先（研修担当者、管理者）を伝える

## GitHub と Codespaces

受講者は、自分の GitHub アカウントに研修リポジトリを fork して Codespaces を使います。

*   [ ] **Codespaces の利用枠の考え方を決めている（重要）**
    *   個人アカウントの無料枠は月に 120 コア時間です。研修では **2-core** の Codespace を使うので約60時間、4-core では約30時間です
    *   試走では 4-core で Day1〜Day2 に 7.47 時間を使い、残りが Day3〜Day5 に必要な時間とほぼ同じになりました。これを受けて、教材の既定を 2-core に変えました（`devcontainer.json` の `hostRequirements` は 2 コア、8GB）
    *   2-core で Day3〜Day5（モノレポの構築、テスト、E2E）が十分に動くかは、試走で確認中です。遅すぎる場合は、そのときだけ 4-core に切り替えます
    *   停止し忘れや遅れに備えて、費用を会社で負担するか、受講を月をまたいで分けるか、を決めておきます
    *   受講者には、使用量の見方（Settings → Billing and licensing → Usage → 検索欄に `product:codespaces`）を伝えます（README にも記載）
*   [ ] ポートの公開範囲を Public にしないことを、受講者に周知している（教材にも記載済み）

## リハーサル（研修担当者）

*   [ ] 研修リポジトリから新しく Codespace を作成し、「recovery mode」にならないことを確認している（devcontainer のイメージタグが存在するかを含む）
*   [ ] Claude Code 拡張と devcontainer が、研修当日のバージョンで動くことを確認している
*   [ ] Claude デスクトップアプリのチャットで AI チューターのプロジェクトを開き、Chrome の画面を確認できることを確かめている
*   [ ] （任意）Vibe Order の完成版を、救済用のリファレンス実装として別ブランチに用意している

## 受講者からの問い合わせ

AI チューターが解決できない問題（アカウントの割り当て、契約、社内ポリシー、教材の誤り）は、受講者から研修担当者や管理者に問い合わせてもらいます。
