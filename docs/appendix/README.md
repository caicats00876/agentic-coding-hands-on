補足:

- `partNN/` の番号は書籍の PART 番号に対応します
- 付録を公開している PART だけを配置しているため、番号が連番にならない箇所があります
- 正式な章構成はルート `README.md` を参照してください

収録対象:

- 長いコードブロック
- プロンプト例
- 設定ファイル断片

収録しないもの:

- 本文説明
- 表
- 箇条書き

運用ルール:

- private 原稿 repo はこの公開 repo の外側に置く
- 付録を公開する PART ごとに `partNN/` ディレクトリを作る
- 各章に `README.md` を置き、用途だけを短く記す
- 抜粋は Markdown ではなく、できるだけ実ファイルとして保存する
- ディレクトリ名は公開資材の識別子とし、正式な章構成はルート `README.md` を参照する
