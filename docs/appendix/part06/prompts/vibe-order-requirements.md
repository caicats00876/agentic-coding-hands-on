# Vibe Order

リアルタイム オーダー管理システム

## 基本コンセプト

席ごとの注文を管理し、ホールとキッチンの情報共有を効率化する。
リアルタイム更新により、注文状況・調理進捗・席の状態を即座に反映。

---

## コア機能

### 1. オーダー管理

- 席ごとにメニューを表示し、品目・数量・オプションを選択して注文
- 注文履歴の一覧表示・再注文機能
- 注文のキャンセル（調理前のみ）

### 2. ステータス管理

- 席の状態
  - 空席 / 着席 / 注文中 / 調理中 / 提供済 / 会計待ち
- 注文の状態
  - 受付 / 調理中 / 提供済
- スタッフの状態
  - 対応可能 / 対応中 / 休憩中

### 3. メニュー管理

- メニューのCRUD操作（画像・価格・説明文）
- 売切れフラグの設定
- おすすめフラグの設定

### 4. リアルタイム通知

- 新規注文をキッチンに即時通知
- ステータス変更を関係者に通知
- WebSocketによる双方向通信

---

## 技術スタック

- リアルタイム通信: API Gateway WebSocket + Lambda
- データストア: DynamoDB
  - テーブル: Seats / Orders / Menu / Staff
- 認証: Cognito（スタッフ用）
- フロントエンド: React + TypeScript
- ホスティング: S3 + CloudFront
- IaC: AWS CDK（TypeScript）

---

## セキュリティ要件

- API Gateway認証（JWT）
- DynamoDBの暗号化（保存時）
- CloudFront + WAF
- 最小権限の原則（IAMロール）

---

## 非機能要件

- レスポンスタイム: 1秒以内
- 同時接続数: 100席まで対応
- WebSocket切断時の自動再接続
