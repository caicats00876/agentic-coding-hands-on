# 自己評価シート

Day5 の最後に、AI チューターと一緒に記入します。自分の fork にコピーして記入してください（例：`docs/worksheets/自己評価_自分の名前.md`）。

点数は 3：できている、2：おおむねできている、1：要支援 です。根拠には、比較シートの数字、日報、Pull Request、設定ファイルなど、確認できるものを書きます。

| 観点 | 3：できている | 点数 | 根拠 |
