# AI チューターのプロジェクトの作り方（研修担当者向け）

AI チューターは、claude.ai の**プロジェクト**として用意し、社内の全員に共有します。受講者は Claude デスクトップアプリのチャットでこのプロジェクトを開くだけで、AI チューターと研修を始められます。

この作業は、Claude の Team プランの**ユーザー権限**でできます。管理者の権限や GitHub の Organization は要りません。

## 1. ナレッジのファイルを用意する

研修リポジトリを PC に clone した状態で、リポジトリのルートで次を実行します。

```powershell
powershell -ExecutionPolicy Bypass -File tutor\build-knowledge.ps1
```

`tutor/knowledge/` に、アップロードするファイル（約40個）がまとまります。ファイル名は、リポジトリのパスの `/` を `__` に置き換えたものです。このフォルダは Git には含めません（`.gitignore` 済み）。

## 2. プロジェクトを作る

1.  Claude デスクトップアプリ（または claude.ai）で **プロジェクト → 新規プロジェクト** を選びます。
2.  名前は「**Agentic Coding 研修 AI チューター**」にします。説明には「受講者はこのプロジェクトで新しいチャットを始め、『研修を始めて』と入力してください」と書きます。
3.  **指示**の ＋ から、[指示文.md](指示文.md) の内容をすべて貼り付けて保存します。
4.  **コンテキスト**の ＋ → **デバイスからアップロード** で、`tutor/knowledge/` のファイルをすべてアップロードします。

## 3. 社内に共有する

1.  プロジェクトの右上の **共有** を開きます。
2.  **一般アクセス**を「**（会社名）の全員**」にします。
3.  受講者には、プロジェクトのリンクではなく、プロジェクトの**名前**を伝えます。リンクを開くと Web 版の claude.ai が開き、そこでは AI チューターが Chrome の画面を確認できないためです。受講者は、デスクトップアプリの **プロジェクト → 組織** タブからプロジェクトを開きます（README の「受講の準備」）。

> [!NOTE]
> 共有しても、受講者のチャットはそれぞれ非公開です。他の受講者や研修担当者からは見えません。

## 4. 教材を更新したとき

1.  リポジトリを最新にして、手順 1 をもう一度実行します。
2.  プロジェクトのコンテキストから、変更したファイルを削除して、新しいファイルをアップロードし直します。すべて入れ替えてもかまいません。
3.  [指示文.md](指示文.md) を変更した場合は、プロジェクトの**指示**も貼り替えます。

## 試走するとき

指示文の中の図やページの URL は、`main` ブランチを指しています。`main` にまだ入っていない教材で試走する場合は、プロジェクトの指示の URL の `blob/main/` を、試走するブランチ名（例：`blob/feature/ai-tutor/`）に置き換えてください。試走用のプロジェクトは、共有せず自分だけで使います。
